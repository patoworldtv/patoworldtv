# 🌍 Patoworld TV (patoworldtv.com)

**Patoworld TV** is a modern, lightweight, and responsive news and entertainment platform built for daily news, sports, entertainment, and general stories in Nigeria and beyond. 

🌐 **Live Website:** [https://www.patoworldtv.com](https://www.patoworldtv.com)

---

## 🚀 Key Features

*   **Custom PHP Backend:** Fast, secure, and optimized for high-speed performance on web hosting environments like Hostinger.
*   **Multi-Category Feed:** Dynamic sorting and filtering across *News*, *Sport*, *Entertainment*, and *General* stories.
*   **Threaded Comments & Replies:** Interactive community discussion system with nested sub-replies and real-time updates.
*   **Post Reactions:** Multi-reaction emoji system (*Like 👍, Funny 😂, Angry 😡, Wow 😲*).
*   **User Authentication & Security:** Secure login, registration, password recovery, session management, CSRF protection, and administrator role toggling.
*   **Live Chat Support:** Integrated real-time visitor support widget via Tawk.to.
*   **Automated Social Syndication & SEO:** Open Graph meta tags, Twitter cards, canonical links, and a dynamic XML sitemap (`sitemap.php`) for Google and Bing indexing.
*   **Rich Media Support:** Seamless uploading and rendering of both image and video attachments.

---

## 🛠️ Tech Stack

*   **Backend:** PHP (Strict types enabled)
*   **Database:** MySQL / MariaDB (InnoDB with full-text search and foreign key constraints)
*   **Frontend:** HTML5, CSS3, Modern JavaScript (AJAX)
*   **Hosting:** Hostinger
